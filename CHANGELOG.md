# Changelog

## 1.0.0

First public Mac build.

- Native Mac workspace. iPhone companion is coming soon.
- Projects are folders (`SOUL.md`, notes, attached files, a workspace).
- Ask-first computer tools, with Always allow as a setting. System paths stay blocked.
- Composio connectors. Oversized tool results are clipped so a long inbox does not blow the model context.
- Window and display control (`control_mac`) when Accessibility is on.
- Sparkle updates from GitHub Releases. Developer ID signed and notarized DMG.
